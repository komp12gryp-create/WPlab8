Вебтехнології

Вебтехнології використовуються для створення сайтів і вебзастосунків. Вони охоплюють засоби для опису структури, оформлення та поведінки сторінок.

HTML

HTML є мовою розмітки, за допомогою якої створюється структура документа. Вона визначає заголовки, абзаци, списки, таблиці та інші елементи сторінки.

CSS

CSS використовується для оформлення HTML-документів. За його допомогою можна задавати кольори, шрифти, розміри та вирівнювання елементів.
